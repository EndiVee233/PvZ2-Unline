# PvP 共享阵容

把游戏导出的 `.pvz2-pvp.json` 文件放在此目录。**一个文件只保存一关**。游戏在开启“联网获取PVP关卡”时会扫描目录下的 JSON 关卡，下载并缓存新增或改动的文件。文件名用来识别同一关卡，更新阵容时请沿用原文件名。

| 字段 | 填写方式 |
| --- | --- |
| 名字 | 最多 39 个字符。留空时，阵容可以由多个随机命名的普通邻居使用。 |
| 奖杯 | 0～99999 的整数。留空时按 `2 × 植物数量 + 3 × 所有植物超过一阶的阶数之和` 计算，自动值最多 150。 |
| 特殊值 | JSON 布尔值 `true` 或 `false`。缺少名字、奖杯或有效概率时，按普通阵容处理。 |
| 出现概率 | 0～100 的百分比，最多两位小数。仅在特殊值生效时使用。0 表示不出现。 |
| 阵容 | 编辑器导出的草坪阵容。每株植物独立保存格子和阶数。 |

共享阵容至少一株、最多 45 株，每格限一株、同种最多 10 株，只能使用陆地防守可用的植物，总阳光不超过 5500。普通阵容按玩家当前奖杯匹配，匹配中心仍以 100 杯为上限。每个可用的共享特殊敌人独立按设定概率抽签，同时命中时从中随机选一位。已有邻居保留原阵容，原有固定特殊邻居仍有优先权。

游戏只在邻居空位或“更换对手”时使用共享阵容。联网开启但目录暂时不可用时，可从此前缓存抽取。没有合适阵容时由本地邻居补位。关闭联网后只抽取本地候选，已匹配的邻居仍保留。

本目录提供普通、通用和特殊三类演示关卡。
