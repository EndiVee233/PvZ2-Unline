# PvP 共享阵容

游戏开启“联网获取PVP关卡”后读取 `catalog.json`。顶层 `format` 为 `pvz2-pvp-catalog`，`version` 为 `1`。每个条目包含稳定的 `id` 及导出的 `formation`。`id` 使用小写字母、数字和连字符，更新阵容时保留原 ID。

共享阵容至少一株，最多 45 株。每格限一株，同种植物最多 10 株，使用陆地防守可用的植物，总阳光不超过 5500。每株植物可独立设置阶数。奖杯为 0–230，实际入池取决于玩家的匹配范围。目录最多收录 24 个阵容。

目录内现有阵容均为演示数据。这里只收录阵容、显示名和匹配奖杯。
