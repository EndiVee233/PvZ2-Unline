## 输入实现

AndroidUIEventManager 对映射按键的首次 ACTION_DOWN 投递 phase6 命令，吞掉同键重复与释放，避免长按连续切换。命令复用原有 UI 队列，x 携带键码，previousX/Y 保存最后悬停坐标。Surface 在触摸和通用移动分发之前检测 BUTTON_SECONDARY，边沿触发取消命令，不让右键变成种植。v19 每次悬停的临时日志已移除。

原生桥仍位于 0x132b660，phase0–4 回到 v20 原有分支；phase5 沿用 v20 坐标转换，并调用资源划过处理；phase6 调用新增 C++ 处理函数。处理函数不引入库依赖，编译为位置无关 ARM 代码追加到已有可执行段。游戏函数通过实际加载基址调用，标准库 Thumb 入口保留 Thumb 位。

## 原生对象与限制处理

UISeedBank 子列表在 +0x48/+0x4c，主栏槽位数使用 +0x11d；按索引解析弱引用并检查 SeedPacket 类型，跳过 DISABLED、ON_DISPLAY、FREE_PLANT 标志（赠送/试用卡不映射）。不存在的槽位直接返回。控件通过 0x976720 检查自身和祖先状态，通过 0x976478 获取实际中心，通过 0x9775d4 检查命中及遮挡。

卡槽、能量豆、铲子、加速和黄瓜最终走应用的原触摸按下/释放虚函数 +0x1c8/+0x1cc。游戏原有 UI 路由、冷却、阳光、可用次数和关卡限制仍参与处理，没有直接改余额、冷却或锁定标志。选择结束后，把预览恢复到最后鼠标坐标，避免停在快捷键点击的控件处。

黄瓜从 UIPowerupHolder 的 PowerupUI 子对象解析 +0xf0 的 PowerupType 弱引用，只匹配 ClassName=PowerupTacticalCuke。暂停使用 Board 原入口 0x20c5e8，恢复沿用关闭暂停界面和 Board 虚函数 +0x58 的原生路径。一般命令在 Board 非进行状态、暂停、模态弹窗时被拦截；暂停命令单独处理。右键仅清除 Board+0x94c 的等待选择，不承诺中断同时按住左键的拖动。

## 划过与 A 键收集

从 Board 输入分发器的监听表中筛选 Collectable，快照弱引用后再调用，避免回调改变监听表导致迭代失效。使用原 Collectable 虚函数 +0xe4（原处理 0x27b584），以移动阶段进行命中检查；原函数负责收集状态切换。标记 0x80 的不可收集物与状态 +0x94==1 的正在收集物跳过。

划过使用已转换为 Board 局部坐标的真实鼠标位置，保留物品原命中范围。A 键只扫描当前快照一次，使用原物品命中框与游戏比例换算中心；不是定时自动收集。暂停和弹窗期间不触发收集。
