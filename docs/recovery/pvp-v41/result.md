# v41：星币实际购买路径与 PVP 钻石余额

v40 用户验收 admin 可重复领取，仍不能购买星币：钻石价格已显示正确，但点击后走通讯、购买界面退出，两种余额均不变。训练未验收。已读取日志、关闭游戏并回档，32 个文件逐一校验通过。

价格配置不会替换原生货币商店按银行模式分发的购买流程。v38 仅挂在成交/通用奖励入口，漏掉了星币商品仍然走旧在线购买分支的实际点击。v41 在两种原生货币商店的真实按钮回调入口 `0x931da8` / `0x9333bc` 识别点击的卡片：校验索引及卡片向量边界，通过卡片 `+0xa0` 的弱引用取得商品，只接管 ObjectType 为 pvpCoin 的三档商品。

本地购买先检查当前玩家账本和星币上限，再通过原有 Profile 钻石扣费方法检查余额并扣费；扣费成功后原子更新本地星币账本，并调用原生星币余额通知刷新界面。钻石不足不发放，账本写入失败返还整笔钻石。仍采用 110→5000、440→20000、1650→75000，未叠加手续费。其他商品和返回/兑换码等特殊按钮恢复原回调参数和函数序言，不进入这笔星币本地交易。

PVP 货币栏本来已创建钻石图标及文字控件，`0x105231c` 会读取当前 Profile 钻石并更新文字，只是初始化 `0x10526d0` 显式隐藏了父控件 CBar_Gem_Back。本版将该 SetVisible 参数改为 true，复用原有布局和余额通知；不新增静态余额、不修改资源包。
