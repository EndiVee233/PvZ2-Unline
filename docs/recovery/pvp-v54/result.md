# v54：首次资源、设施升级与邪恶戴夫战斗候选

v53 星光修复已由用户确认全部正常。新开的戴夫入口诊断批次也已结束，32 个存档文件回档并逐一校验。

## 本版实现

- 每名玩家首次建立离线 PVP 经济记录时发放 1000 星币、200 奖章；保存一次性标记，重进和重启不重复发放。旧版已有经济文件保留原星币与军队，新字段迁移为版本 2；首次教程期间保留教程临时军队。
- 自家基地在 BigMapInfo 中补充所属玩家、余额、容量及产速，修复基地详情 0/0、产出 0 的缺项。基地初始容量分别为 2000，每小时生产 40 星币、20 奖章；资源达到容量后停止生产，钻石购买的超容量余额不被削减。
- 从原 PVPUPGRADE.RTON 提取基地、阳光上限、军团容量各 20 级数据，不修改原配置资源。基地 1→2 消耗 150 星币、计时 4 小时；原生 Lab 的类型 1/2/3 等级、倒计时和本地保存同步。跨重启、离线到期仍可完成，升级完成前后分段计算基地生产。
- 进行中的设施升级使用现有普通按钮显示“X钻石立即完成”，复用原确认窗口并替换现金路径。按原分钟档位报价，确认后扣钻石并完成升级；取消、钻石不足和落盘失败不会完成，落盘失败返还钻石。
- 戴夫房屋 native handler 设置的 +102 标记会让 ArenaBattle 留在等待在线启动的 state 1。离线攻击清除该标记及在线播放标记，保留戴夫专用 kind=1；侦察转进攻继续沿用原地开始，不重复生成植物。
- 经用户明确选择，戴夫暂用独立本地阵容（10 株植物，区别于六个普通邻居）。这是离线替代阵容，不宣称原版服务器阵容已恢复；原版阵容仍待寻找。成功取得星级时在同一经济事务中保存戴夫完成状态，失败或撤退不记胜。
