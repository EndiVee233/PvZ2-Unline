# v80 商铺进攻与三星占领（候选）

v79 商铺只读侦察、阵容切换、停留、免费放弃、住宅返回和重启已获用户验收，33 文件已回档。继续接通商铺战斗和归属保存，驻防、生产及收租暂不实现。

## 用户确认的规则

用户凭原版记忆纠正：三星占领，非三星胜利仍有奖励。原服务器完整数值未找回，用户进一步明确选择离线替代公式：侦察免费，开战扣 1 星币；0／1／2／3 星分别奖励 0／33／66／100 星币，三星另获得该商铺。奖章、钻石和排名奖励不新增。此公式不声称复原原服务器。

## 进攻与结算

保留原生商铺大按钮的命中区域和军队检查，真正请求进入本地进攻处理。侦察内开始攻击调用原生 ArenaBattle 开始方法，在同一草坪展开，不重新摆放植物。地图直接出击载入同一套商铺中立阵容与军队。未训练的僵尸不得出战，缺军队/星币时不扣费。

沿用已验收的单次开战日志与战斗军队结算：重复请求不重复扣费，载入失败尚未创建卡槽时重启退费，已经开战则保留费用。存活或未投放僵尸回收，明确阵亡的才扣除。三星占领位、星币奖励和军队变化与结束日志写入同一份原子文件；失败时均不更新，重试只完成一遍。

占领后原生商铺记录的 owner 对应当前玩家，显示“您的资产”并打开自有商铺面板，此时为真实已占领状态。重启时从各玩家独立钱包恢复。旧内存中的上一玩家归属也在换玩家时清除，外来商铺记录不覆盖。已经占领的商铺不能重复进攻刷奖励；自有商铺的驻防/收租按钮暂拦截网络，不把它们算作已恢复。
