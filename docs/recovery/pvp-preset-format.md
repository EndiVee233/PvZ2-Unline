# PVP 阵容文件 v2

本格式只包含阵容数据，用于独立布阵、导入导出及共享匹配。共享目录的索引和收录要求见 [`pvp-presets/README.md`](../../pvp-presets/README.md)。

示例：同种豌豆射手混合一阶和三阶。

```json
{
  "format": "pvz2-offline-pvp",
  "version": 2,
  "名字": "混阶豌豆防线",
  "奖杯": 30,
  "特殊值": false,
  "出现概率": null,
  "columns": 9,
  "rows": 5,
  "tierMask": 5,
  "阵容": [
    {"type": "peashooter", "row": 0, "column": 0, "level": 1},
    {"type": "peashooter", "row": 1, "column": 0, "level": 3}
  ]
}
```

- 行列从0开始，草坪为9列5行，每格最多一株，总数最多45。
- `type` 使用原包植物别名，预设卡槽与邻居匹配使用同一份可用植物名单。阶数限制为1～4且不超过植物本身支持的最高阶。
- `tierMask`低四位分别对应一、二、三、四阶。设置页选择其中一阶，作为该次布阵中新放植物的固定阶数。导入时按“阵容”中的 `level` 恢复已放植物，也接受旧版写出的多位掩码。
- 创建或导入后，在原版风格的阶数页打开“关卡资料”修改四个字段。名字可留空，最长39个字符；奖杯留空时自动计算。出现概率采用百分数，支持两位小数。名字、奖杯、概率未填齐时，特殊值回退为普通阵容。

- 每个文件保存一关。旧版 v1 的 `name`、`trophies` 和 `plants` 文件仍可导入，再次导出时转换为 v2。
- 文件最大64KB。版本、植物别名、格子、等级或重复占格不合法时拒绝导入，不覆盖当前阵容或玩家进度。
- 系统导出的建议扩展名为`.pvz2-pvp.json`，通过系统文件选择器选择保存位置，可直接分享该文件。
- 保存并退出会把关卡写入 `Android/data/com.popcap.pvz2cthd.reconstruction/files/pvp_level/`。从“修改PVP模式预设阵容”进入“本机关卡”，可以打开编辑或导出副本。旧版最近草稿会以 `previous-draft.pvz2-pvp.json` 迁入。

- 游戏在启动和保存后读取 `pvp_level/` 顶层的本机关卡用于匹配。开启联网获取后，再加入 `pvp_level/github/` 中经过校验的 GitHub 缓存。关卡仍需满足共享防守阵容的校验条件才会进入匹配池。

编辑器使用原版布阵场景和独立的 `arena_preset_editor` 关卡定义。临时解锁、卡槽等级和阳光只作用于编辑会话。退出时恢复进入前的 PvP 管理器阵容和模式。

打开含有禁用植物的旧文件时，编辑草坪会跳过这些植物。保存时才写入修改后的阵容。需要分享旧文件时，请先打开编辑并保存。每格限放一株植物。
