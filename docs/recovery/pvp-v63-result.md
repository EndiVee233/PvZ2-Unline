# v63：僵尸进阶扣费、计时与本地等级

状态：候选版已构建，程序检查通过，未通过用户运行验收。v62 仅验收了列表选择、一级及费用说明，没有把它标记为完整进阶功能恢复。

## 实现范围

从当前原始 `ZombieTypes` 与 `PropertySheets` 关联生成 12 种可训练僵尸的费用和时间，不编辑属性资源。普通战斗僵尸三次进阶原值分别是 100／300／900 星币、30／60／120 分钟，对应一阶到四阶。原生等级倍率和技能数据由引擎保留，不自行叠加第二次倍率。

钱包 v4（304 字节）追加各僵尸等级及一个进阶队列，兼容读取 v1/v2/v3。首次初始化导入已有合法原生等级；缺失的独立实验室记录从一级建立，不把训练库存当等级。扣费、队列及等级与钱包在同一次原子替换中保存。建筑升级和进阶共用一个实验室计时槽，不能互相覆盖。

队列用绝对到期时间冷启动恢复，自然到期只升级一次。立即完成复用既有钻石报价及确认窗口；确认时核对玩家、目标和原到期时间，避免旧确认框完成另一条队列。保存失败不改变等级，已扣钻石退还；重复完成不再收费。

进阶页保留原布局、选择条与说明，计时期间使用原生普通按钮显示“X钻石完成(剩余分钟)”，绕开旧现金覆盖按钮。满级隐藏购买按钮。原生 PVP 投放函数 `0x108c2b4` 从同一僵尸记录读取等级并传递给草坪生成僵尸的方法，因此不是只改页内数字；实际伤害/血量仍需游戏内分项验证。

药剂/海鸥贴图和技能入口闪退仍在待办；本版不恢复技能研究或修改这些资源。
