# v58：药剂动画比例候选版

v57 用户确认实际范围正常，视觉部分未通过。该轮游戏已关闭、33 个存档文件已回档校验。本版保留 v57 判定，仅修改动画与启动时资源更新流程。

## 原因与处理

v32 从旧包补入的 640 贴图被选为 1536 组，但 PAM 内引用图像的变换基仍沿用小图比例，动画位移与部件大小不匹配。鹦鹉的部件不能通过缩放整只鸟来重新拼合。

对治疗、迷雾、瘟疫的四份 PAM，按 1536/640 修正图像变换基。保留全部骨骼/帧位移、播放速度、标签、指令、添加/删除对象与时间轴，不改变图集裁切及像素。三种技能共有的圆形图像变换与 1536 狂暴资源相同，图集尺寸相差约 2.4 倍，可相互对照。

在校正资源比例后，治疗地面 idle 段按 4/3×4/3 扩大；狂暴地面 idle 段按 5/3×4/3 调整。偶数边长的视觉中心向前半格移动，与 v57 选中提示约定一致。迷雾恢复到同规格原三格圆环；瘟疫落地 idle1 段另放大 1.25 倍。飞行鹦鹉、投掷和碎片动画不采用地面范围的拉伸。

图像资源没有重新采样。本版通过动画几何修复比例，不是模糊放大贴图。圆环及烟雾是美术表现，不代表矩形角落没有效果；判定仍为已验收的 v57 矩形。

## 验证边界

动画重新解析检查标签、指令、帧数、对象增删不变；图集像素及其他资源组保持不变。v57 的 ARM 范围检查和既有主要回归检查继续执行。还需用户在 WSA 验证鹦鹉完整、地面特效比例与位置及结束清理，不将自动检查当作视觉验收。

启动器更新资源校验值、文件长度与标记，并接受 v32–v57 使用的旧技能资源作为更新前身，避免覆盖安装后因旧资源摘要不匹配而无法启动。
