# v31：离线 PVP 基地与地图入口

本阶段仅恢复原版 PVP 基地及花园战争地图的进入、显示与返回，不代表训练、实验室、敌人生成、资源生产、排行榜或完整对战后端已经恢复。

## 实现

- 战役地图对战按钮 `0x1021f4c` 改为请求原生场景 28（PVP 基地），不再直接进入 v30 教学战斗。已有 NPC 战斗和动画缓存代码仍保留。
- PvPGameManager 的基地等级及当前区域等级只在小于 1 时设置为 1，保留有效值；地图类型使用原流程的 2。进入前清除 LawnApp 的练习战斗模式值，不修改云同步标志或伪造云端登录。
- 基地花园战争按钮 case 1 的 `0x107becc` 改为请求原生场景 25（PVP 街区地图）。保留原 UI 的返回和场景清理。
- 关闭四处旧请求：`0x107b70c` 基地自动登录、`0x100c8b0` 地图初始化读取、`0x353f1c` 场景返回时登录、`0x353f80` 场景切换时地图请求。另关闭 PVP 管理器初始化的状态预取（0x1049fcc）、地图查询（0x1042934）和配置查询（0x1042960），后者保留原标志位清理。其余功能的服务器接口未假装恢复。
- 使用游戏已有原生资源和默认初始状态，地图暂只显示本地基地；敌人列表与军队数据需后续恢复。

## 反编译依据
