## 已确定的崩溃原因

只读取日志，未安装、启动或操作游戏，未清理日志或存档。2026-11-02 00:05:46 的 Houdini ARM 回溯为 libSrc.so+0x1a0132c，LR=libSrc.so+0x11e5914。此处新桥接代码在调用对象虚函数 +0x10 后，把返回值当对象地址读 +0x10c。

原接口 0x11e58f0 实际为类型判定，返回 bool。原生调用者均判断返回值后使用原对象。v22 的 cast 辅助函数错误地返回此值作为指针，因此成功判定返回 1 时访问接近零的地址。此错误也影响黄瓜 UI 类型筛选的后续取字段，现统一改为判定成功返回原对象，失败返回空。

v22 隔离检查把此接口模拟成返回对象指针，掩盖了错误。v23 检查改为返回实际布尔值 1，执行真实编译 ARM 代码，在两个加载基址下均通过。

## 暂停路径

v22 空格在 Board 进行状态下直接调用 0x20c5e8，跳过了鼠标输入的教程/对话拦截。v23 改为查找 UIPauseButton、检查可用与遮挡，通过同一 click 辅助函数产生应用原按下/释放事件（虚函数 +0x1c8/+0x1cc）。后续教程拦截由原输入路径处理，不直接调用暂停函数。

恢复仅限 Board 已暂停、应用存在暂停菜单（+0x1378）且无模态弹窗。没有暂停菜单时不会强行恢复，以免解除教程或其它系统暂停。暂停菜单存在时沿用原关闭菜单及 Board 恢复路径。
