# v75 本地基地布阵保活与退出（候选）

保留 v74 用户确认正常的邻居住宅分类、标牌、详情和侦察转进攻。本轮修复用户额外发现的自家基地布阵崩溃，不推进商铺占领。

## 原因与修复

- 原生 ArenaPlant 更新每约三秒发送 action 1，销毁时发送 action 3；此前离线请求方法只处理普通战斗模块的 action 2/4。布阵走到未初始化的旧网络对象，在 `0xf8c8d0` 的原生字符串复制时崩溃。
- 在离线自家布阵入口记录当前用户，清除上场住宅侦察/服务器准备标记。只有该用户且当前关卡确为 `arena_plant_test` 时，本地确认 action 1，将 app `+0x185c` 更新为原生单调时钟 `+0x18`，与原生超时判定使用同一时间来源。
- 原生布阵销毁 action 3 在同一用户会话内直接清理本地会话；令牌保持到场景拆卸完成，即使 board 已被移除也不会重新发送服务器请求。普通战斗、其他玩家与早期教程不套用此分支。
- 保存阵容仍走已有本地序列化；不保存退出不写入阵容。没有修改实际玩家存档推进测试。

## 检查边界

专项在编译后的 ARM 代码上覆盖真实请求入口和原生 app 时间读取、连续 45 秒布阵保活、继承住宅预览标记后进入布阵、board 已卸载时退出请求、不变的货币、保存与重进/重启，以及不保存丢弃改动。跨玩家请求必须不误认作上一玩家的本地布阵。跨玩家拒绝用例故意触发模拟网络边界断言，日志 `FAULT PC` 不代表 WSA 运行崩溃。
