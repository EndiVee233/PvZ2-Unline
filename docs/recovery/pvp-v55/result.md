## 修正

- 自家基地弹窗是 context kind 4。构造代码 0x10191fc 读取 PVPManager+0x138 至 +0x14c，再写入弹窗的六个资源字段；v54 只填写了邻居使用的 BigMapInfo，故依旧 0/0。本版同步这组六字段，涵盖两种余额、两种容量和两种产速。保留 v54 的升级事务与原配置。
- 戴夫的房屋侦察以零玩家 ID、reason 4 请求进入专用场景。保留 kind=1，但设置 preview 标记；reason 1/2 的进攻清除此标记。补全零玩家 ID 对房屋上下文的解析，使预览内攻击可以沿用原生 ArenaBattle::StartBattle，不重新载入、也不叠种。
- 原 Zombie 回卡函数在 0x290f14 已调用 PVPZombieSeedPacket 的数量设置方法，再于 0x290f24 生成 WORD_EFFECT。只移除后者，保留真实数量返还。
- AddEnergyEffect 状态 3 在 0x10402cc 至 0x10404b4 之间生成独立到账闪光；状态 4 根据计时执行原能量到账回调。只跳过最终闪光生成，飞行、状态推进、到账和事件通知保留。没有停用公用特效工厂或跳过到账回调。
