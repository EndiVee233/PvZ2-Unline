# Aster：架构同步与玩家选择记忆

源码提交后，已发布 [Aster v163 双架构安装包](https://github.com/EndiVee233/PvZ2-Unline-Aster/releases/tag/v1.7.5-v163-aster-dual-arch)。ARM32 推荐，ARM64 实验包不推荐。附件保持已验收/已同步构建时的原始字节，内部版本均为 v163（1163），没有为发布重新打包。游戏内更新器暂未适配双架构附件名，请手动下载。

## 玩家选择记忆

选择玩家时保存稳定玩家标识，启动时恢复上次选择，避免总是落到第一个槽位。缺少或失效的记录沿用游戏的回退流程。该补丁作用于 ARM32 引擎；ARM64 构建以同一已修补 ARM32 APK 为输入。

用户已在 WSA 的 ARM32 版验收：选择 WSA USER 后冷启动仍为 WSA USER；切换全一 TEST 后冷启动保留；再切回 WSA USER 后保留且原进度正常。此结果来自用户反馈，本次上传未另行运行游戏测试。

## 其他同步源码

- Aster 独立包名与构建入口。
- ARM64 桥接所需的 JNI、GLES、文件和系统调用适配源代码。
- Tab 不再把焦点移到隐藏输入框；加速短白闪结束后恢复正常画面及快捷键。
- 资源解包、RGBA 后台预处理、PVP 货币布局和离线入口的后续维护代码。

ARM32 为推荐版本。**不推荐 ARM64，优先使用 ARM32。** ARM64 当前同步候选未验收，性能及实体设备兼容性未确认；只有收到明确 ARM64 issue 后再调查，不主动复查。未来发布分别提供两种架构并标注各自状态。

## 保留事项

- 四种 PVP 技能高清贴图和动画比例待修复。
- 战斗回放未实现。
- 戴夫刷新周期及商铺原版阵容、产出数值尚未还原；现有离线商铺产出和静默袭击按用户确认的替代规则运行。
- 原版资源、游戏原生库、私有存档、签名密钥及诊断输出不随源码提交。
