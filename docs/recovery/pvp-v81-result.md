# v81 已占领商铺驻防（候选）

v80 商铺进攻、即时奖励、三星占领及重启归属已获用户验收，测试后恢复校验 33 文件。下一项恢复驻防；生产和收租不在本版范围。

## 原生入口与编辑器

原生自有资产按钮 201（布置防守）原本发送服务器阵容请求。候选仅在真实已占领的两处本地商铺接管该按钮，复用原生 `arena_plant_test` 编辑器。入口与保存都同时校验当前玩家、钱包中的占领位、地图商铺记录归属、正在编辑的目标；未占领或另一个玩家的商铺不能进入/保存。

自家基地仍为 kind 1、商铺为 kind 2，并绑定明确的商铺 ID。切换编辑目标前结束旧 board，再载入对应阵容；保存成功后先 Board::Finish 再回地图，写入失败则保持编辑现场。保留原生选卡、阳光、铲除返还、暂停和不保存退出。编辑会话用显式 active 位区分编号为零的玩家与未启动/已结束会话。

新占领商铺初次进入为空阵，不沿用进攻阶段的中立阵容。重复进入同一活跃商铺编辑器不重建或丢弃未保存修改。每次真正重进从已保存版本重新载入，不保存退出不写入。

## 独立保存

基地既有 `.def` 格式与路径不变。商铺写入按当前玩家、商铺 ID 独立命名的 `offline-pvp-<player>-shop-<target>.def`，保存包含版本、玩家、目标、整包校验和，以及原有带校验的植物位置/类型/等级/外观/签名阵容。先写临时文件、同步成功再原子替换；损坏、截断、尾部多字节、错误商铺或错误玩家的文件不能静默当成空阵覆盖。

本版不更改钱包格式，不因驻防扣星币、钻石或僵尸，也不提前提供租金。驻防文件和日志同属私有存档，全部位于既有快照覆盖目录，不能上传。
