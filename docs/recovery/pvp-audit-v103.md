# v103 离线 PVP 功能审计

基线为已安装的 v103。对照了 1.7.5 原包的 `LAWNSTRINGS.TXT`、当前离线代码、同期资料及逐版验收记录。本次完成上轮回档，未开启新的运行测试。

## 已恢复的主流程

地图、六区解锁、随机住宅邻居与更换、侦察/进攻/结算、部队训练/出售、基地布阵和升级、两处商铺占领/驻防/收租、奖章商店购买及刷新、静默袭击、攻防摘要和失败后的复仇侦察已接通。各项验收以对应记录为限。用户已确认僵尸贴图完工，联赛与排行榜按要求删除。普通进攻收费与奖励、袭击概率、商铺产速和地区价格采用已确认的离线规则。

- **每日任务或活动**。失落之城上线报道提到限期胜利送钻石及每日成就。原包还保留每日获胜额外奖励的联赛文案，两者是否属于同一入口、哪些是 1.7.5 的常驻玩法，仍需考据。已明确删除的联赛专属奖励保持移除。见 [同期上线报道](https://m.4399.cn/news-id-598410.html)。
